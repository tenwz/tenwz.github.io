# 滕文证 Teng Wenzheng

纯粹的 txt 网站：主页就是一个文件目录，点开即真正的 `.txt` 纯文本（text/plain）。无样式、无构建、无依赖。

部署在 GitHub Pages：<https://tenwz.github.io>

## 文件结构

```
├── index.html   # 目录页：构建时由 Jekyll 自动列出所有 .txt，无需维护
└── xxx.txt      # 文章，纯文本
```

## 如何写新文章

1. 在根目录新建一个 `.txt`，直接写正文。
2. 想要右边留白的效果，就自己控制换行：正文每行写到固定字数就断行
   （RFC 的做法是每行 72 字符；中文可以每行 30 个汉字左右）。
   行短了，宽窗口的右边自然就空了。注意窄屏上长行会被浏览器再折断。
3. 提交推送。目录由 GitHub Pages 内置的 Jekyll 在构建时自动生成
   （`site.static_files`），新 txt 出现即自动出现在首页，无需改任何文件。

## 绑定自定义域名

如果想用 `reed.wiki` 之类的自定义域名：

1. 在本仓库根目录添加 `CNAME` 文件，内容为域名（如 `reed.wiki`）；
2. 在域名 DNS 中添加 4 条 A 记录指向 `185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153`；
3. 仓库 Settings → Pages 里确认域名并开启 Enforce HTTPS。
