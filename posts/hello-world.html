重新开张：把博客搬回 GitHub Pages

2026-09-12

博客重新开张了。这次选择最简单的方式：纯 HTML + CSS 的静态页面，托管在 GitHub Pages 上，没有构建步骤，没有数据库，写一篇就是提交一个 HTML 文件。

为什么这么简单

之前折腾过各种博客框架，最后发现真正的问题不是功能不够，而是维护成本太高——依赖升级、模板迁移、本地环境，每一次想写点什么之前都要先解决一堆别的事。

静态页面刚好相反：git push 之后一分钟内就能在线上看到，十年后依然能打开。

接下来想写什么

  • 折腾工具的过程和心得
  • 量化与数据相关的实验记录
  • 一些不成体系的小想法

写下来，就算学会了。
